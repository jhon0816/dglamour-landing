# D' Glamour MC Landing

Landing page estática para D' Glamour MC, emprendimiento de uñas, pedicure y trenzas en Cali.

## Estructura

- `index.html`: página principal.
- `assets/img`: fotos reales usadas en la galería y el hero.
- `assets/js/main.js`: menú móvil y año automático del footer.

## Cómo verla

Abre `index.html` en el navegador. La página usa Tailwind CSS y Font Awesome por CDN, así que para ver los estilos e iconos completos necesitas conexión a internet.
